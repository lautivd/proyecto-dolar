# Análisis del dólar y la inflación en Argentina

Este es un proyecto personal que estoy desarrollando mientras aprendo Python y Ciencia de Datos.

El objetivo es analizar cómo fue evolucionando el dólar en Argentina, cuánto aumentó a lo largo del tiempo y qué relación tiene su comportamiento con la inflación.

A través de datos históricos y gráficos, busco comparar ambas variables para entender mejor cómo se relacionan y si las subidas del dólar coinciden con los aumentos de precios.

## ¿Qué se analiza?

* La evolución histórica del dólar blue en Argentina.
* Las variaciones del dólar a lo largo del tiempo.
* La comparación entre el dólar y la inflación.
* La relación entre las subidas del dólar y los aumentos de precios.
* La visualización de los datos mediante gráficos.

## Herramientas utilizadas

* Python
* Archivos CSV
* Git y GitHub

## Objetivo del proyecto

Quiero entender mejor el comportamiento del dólar en Argentina y analizar cómo se relaciona con la inflación.

Una suba del dólar puede influir en los precios de los productos y servicios, pero esa relación no siempre es inmediata ni proporcional. Por eso, comparar los datos históricos permite observar tendencias y explorar posibles relaciones entre ambas variables.
